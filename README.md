# 數位易經 · 三數起卦（優化版 v3）

三數起卦的易經占卜，提供八大類別詳細解讀，並保留占卜紀錄。

**線上使用**：https://kftseng2oo1.github.io/v3/

## 主要功能
- 三數起卦：第一數 ÷8 定上卦、第二數 ÷8 定下卦、三數相加 ÷6 定動爻
- 八大類別：事業、健康、愛情、財運、投資、購物、官司、購屋，記住上次選的類別
- 顯示卦名、動爻爻辭與該類別的白話解讀
- 📜 占卜紀錄：自動保存，可加註記
- 分享結果、複製文字、震動回饋
- 📖 內建使用說明（起卦原理、使用技巧）

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- 紀錄存在 localStorage：`divinationHistory`、`lastCategory`
